# 学习路线与框架地图

## 1. 先把“框架”分层

很多产品都自称 Agent Framework，但并不处在同一层。

可以先用下面的心智模型：

```text
业务 Agent / Copilot / Research System
              │
              ▼
      Application Framework
   Spring AI / LangChain4j
              │
              ▼
     Orchestration Runtime
           LangGraph
              │
              ▼
      Agent SDK / Harness
 OpenAI Agents SDK / Claude Agent SDK
              │
              ▼
       Model / Tool / MCP
```

这不是严格的产品上下层依赖关系，而是“主要解决的问题层次”。不同产品会跨层。

## 2. 第一阶段知识映射

| 你已经学过 | 框架世界常见名称 |
|---|---|
| LlmClient | ChatModel / Model Client |
| AgentLoop | Runner / Agent Executor / Tool Loop |
| ToolRegistry | Tools / Function tools / callbacks |
| Message History | ChatMemory / Session Events |
| ContextBuilder | Advisor / Middleware / Retrieval Augmentor |
| State | Thread / Session / Graph State |
| Checkpoint | Checkpointer / Persistence / Durable execution |
| Plan | Planner / Workflow state / sub-agent orchestration |
| Handoff | Delegate / transfer / agent-as-tool |
| Trace | Observability / spans / events |
| Harness | Runner + environment + tools + permissions + state |

## 5. 最终你应该得到什么

不是“我会 6 个框架”。

而是：

```text
业务问题
   ↓
判断复杂度
   ↓
需要普通 Tool Agent？
需要状态编排？
需要长任务恢复？
需要 Multi-Agent？
需要 Harness / Sandbox？
   ↓
选择合适抽象层
```
