# 版本与官方文档策略

Agent 框架 API 变化速度快，本教材刻意把“稳定概念”和“易变 API”分开。

## 规则

实现每个 Prompt 前，AI 编程工具必须确认：

1. 当前官方稳定版本；
2. 本章涉及 API 是否仍推荐；
3. 官方 quickstart / reference 中是否有替代接口；
4. 依赖坐标是否准确。

## 官方来源优先级

1. 官方 reference / docs
2. 官方 GitHub repository / examples
3. Maven Central / PyPI 等官方包索引
4. 官方 release notes

不要优先依赖：

- SEO 博客；
- 两年前的教程；
- 未注明版本的 StackOverflow 代码；
- 模型记忆中的旧 API。

## 当前重点官方文档入口

- Spring AI: https://docs.spring.io/spring-ai/reference/
- LangChain4j: https://docs.langchain4j.dev/
- LangGraph: https://docs.langchain.com/oss/python/langgraph/overview
- Google ADK: https://google.github.io/adk-docs/
- OpenAI Agents SDK: https://openai.github.io/openai-agents-python/
- Claude Platform Agent/Tool docs: https://platform.claude.com/docs/
