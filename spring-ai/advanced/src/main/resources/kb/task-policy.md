# 任务处理规范（教学知识库）

> 本文件是 Ch04 RAG 实验的检索语料。共 3 个段落，ingest 时按二级标题切段。

## BLOCKED 任务升级处理

当任务状态变为 BLOCKED 时，负责人必须在 4 小时内发起升级。
升级流程：先在任务备注中写明阻塞原因和已尝试的解法，
然后通知直属负责人，并把任务优先级提到最高一档。
若 24 小时内仍未解除阻塞，自动上报到周会待办清单。

## DONE 任务归档

任务标记为 DONE 后，需等待 7 天观察期，期间无回归即可归档。
归档时把任务摘要、处理人、耗时写入归档目录，原始任务记录保留只读快照。
归档后的任务不再参与日常统计，但可在审计时按编号检索。

## 高优先级任务响应时限

高优先级任务必须在 1 小时内首次响应，4 小时内给出处理方案。
响应是指在任务下留言或更新状态，而不是私下口头承诺。
超时未响应的任务会自动标红，并计入当周响应率统计。
